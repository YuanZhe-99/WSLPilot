# 图形界面

WSLPilot 窗口的构成（`internal/gui`、`cmd/wslpilot`）。各页面依照 `design/` 中的设计稿；窗口外壳、设置面板与更新流程沿用
MyGo 应用 Kyokai 与 EasyTier MyGo 的做法。编写视图的规则见 `architecture.md`（“UI 线程”）与 `.agents/skills/mygo-maintenance`。

## 窗口外壳

| 部分 | 行为 |
|---|---|
| 框架 | 隐藏系统标题栏（`gui.TitleBarOptions`）；窗口背景为 Mica。侧边栏直接画在 Mica 上，页面画在其旁的面板上；面板距窗口边缘 8 px（距侧边栏 4 px），在 Windows 与 Linux 上圆角为 4 px（macOS 为 12 px），因此圆角不会超出窗口的圆角（与 Kyokai 相同，`paneCorner`）。 |
| 面板页眉 | 页面图标、标题与一行说明（子页面把上级页面作为链接放在前面：“Compose › vocechat”）；它就是标题栏：拖动可移动窗口，双击可最大化。右侧是页面操作，在 Windows 上再右是 WSLPilot 自绘的最小化、最大化（支持贴靠布局）与关闭按钮。 |
| 侧边栏 | 应用图标（企鹅）与名称及收起按钮、带 Lucide 图标的各页面，底部为“任务”（显示运行中任务数）、外观切换（跟随系统 → 浅色 → 深色）、“设置”与版本号。收起后是一列图标，名称显示在提示中（`sidebarRail`）。 |
| 关闭 | 保留在托盘中运行，除非在“设置 › 常规”中选择“退出”；第一次关闭时用通知说明窗口去了哪里（`closeHinted`）。 |
| 托盘 | 打开 WSLPilot、检查更新（打开设置的“关于与更新”并检查）、退出。 |
| 隐藏启动 | 登录时启动（除非关闭了“启动到托盘”，`loginWindow`），以及窗口关闭期间安装更新后重启（`relaunchHidden`）。 |

## 设置面板

设置是覆盖整个窗口的面板，而不是一个页面。左侧是搜索框与分组列出的分区；右侧以行显示所选分区：图标方块、标题、一句说明与控件。

| 组 | 分区 | 行 |
|---|---|---|
| 偏好设置 | 常规 | 外观、语言（跟随 Windows、English、简体中文；立即生效）、登录时启动、启动到托盘（登录时不打开窗口；关闭此项则打开窗口）、关闭窗口时（保留在托盘或退出） |
| 本机 | 备份与代理 | 后台代理、默认备份文件夹、Volume 辅助镜像 |
| 本机 | WSL 容器 | 数据位置（移动）、重启 session、`settings.yaml` 表单 |
| WSLPilot | 关于与更新 | 版本与源代码、开源许可证、更新、数据文件夹 |

搜索匹配各行的标题与说明；选择结果会打开对应分区、滚动到该行并短暂高亮。

## 更新

WSLPilot 在应用内更新自身，不使用 MyGo 的更新窗口插件。发布包经过签名（`mygo.json` 的 `updates`，见 `ci-cd.md`），
且只有安装版能够更新（`Updater.Enabled`）：便携版或开发构建会显示“此构建不提供更新。”

| 设置 | 行为 |
|---|---|
| 每天检查更新 | 默认开启。WSLPilot 运行期间每天检查一次（到期时在启动 10 秒后首次检查），每个新版本只提醒一次（`announcedVersion`）。 |
| 自动安装更新 | 从不（默认）、电脑空闲 15 分钟后，或每天的指定小时。仅在没有任务运行时进行；失败后等待 6 小时再试。 |
| 安装并重启 | 带进度下载、校验签名、安装并重新启动；原本在托盘中的窗口重启后仍留在托盘。 |

更新循环与 `autoInstallDue` 位于 `internal/gui/update.go`；相关偏好设置见 `app-data.md`。

## 页面

| 页面 | 内容 |
|---|---|
| 概览 | WSL、WSL 容器与 Compose 的统计卡（数字、状态胶囊、一行说明、链接）；同一刻度的磁盘占用条（已用、可回收，或在未测量内部用量时显示磁盘占用）；活动（运行中任务、最近结果、下次计划备份）；快捷操作。 |
| WSL | 发行版表格（默认胶囊、状态圆点、版本、大小、位置）与所选发行版的卡片：操作按钮网格、稀疏磁盘、带步骤与“先备份”的内嵌压缩面板、注销。发行版设置以独立页面打开：面包屑、`wsl.conf` 与 `.wslconfig` 之间的切换、标记“已更改”的分组行，以及待保存更改卡片。 |
| 容器 | 以分段切换容器、镜像与网络；容器表格（状态、端口、CPU、内存、重启策略、Compose 项目）与所选容器的日志：深色控制台、搜索、Shell、重启、停止及更多操作。 |
| Compose | 项目卡片；项目页面包含服务卡片（镜像、用量、端口，以及每个挂载“来源 → 目标 · 目录或 Volume”）、“数据”卡片，以及在出错行显示诊断并附问题列表的 `compose.yaml` 编辑器。“数据”卡片用与 Volume 页面相同的名称列出项目保存数据的位置：每个 Volume（大小、使用的服务、在 Volume 页面中打开）与 bind 目录（大小、使用的服务、在资源管理器中显示）、外部 Volume，以及用“存放位置…”把命名 Volume 放在 Volume 或 Windows 目录中。“备份项目…”先显示备份包含的内容以及是否停止项目。“移除容器…”即 `compose down`；“从 WSLPilot 中移除…”只是忘记该项目。 |
| Volume | Volume 表格，下方是所选 Volume 的操作（导出 TAR、备份、vhd Volume 的压缩、删除），旁边是 TAR 导入面板（导入为新的 Volume，或在安全备份后替换 Volume 的内容；导入后检查条目数）。“使用者”先列出所属的 Compose 项目（可点击打开），再列出容器；这样的 Volume 即使项目已 down 也不算“未使用”，选中时提供“备份项目…”。“删除未使用的”会删除其余没有容器使用的 Volume，并逐个先备份。 |
| 备份 | 以还原为先：打开任意位置的备份、可还原的内容、位置，然后是所选来源的版本，以及分步还原卡片；项目备份会列出其中的文件、目录与 Volume，可还原整个项目或其中一个 Volume。在版本上右键可以检查或删除它（增量版本会合并到下一个版本）。计划：计划表格，以及以“标签 — 值”行显示的所选计划，含“立即运行”“编辑”“删除”与运行记录；计划编辑器用文字显示时间表与类型，从列表中选择时间，并标出已包含在所选项目备份中的 Volume。 |
| 终端 | 发行版、容器或 PowerShell 中的 Shell 标签页。 |
| 任务 | 本次运行中的每个任务，含进度与日志。 |

## 构件

布局数值与颜色是 `internal/gui/style.go` 中的命名常量；图标是 `internal/gui/icons.go` 中的 Lucide SVG。共用构件：`card`、`pill`、
`stateText`、`bar`、`callout`、`emptyState`、`iconButton`、`actionButton`、`labeledSelect`（保存取值、显示标签的下拉框）、`dataRow`（一个数据位置，用于 Compose 页面与备份），行式列表（`rows.go`），以及每个页面页眉使用的 `paneHead`。
在选中的表格行上，彩色标签改用该行的文字颜色（`selTone`）。
