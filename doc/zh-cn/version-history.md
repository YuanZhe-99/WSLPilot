# 版本历史

## 0.1.4

2026-11-06 发布。在 Windows 11 ARM64 上基于 WSL 3.0.3.0、WSLc 3.0.3.0 与 MyGo v0.8.1 测试。

- 修正：在托盘中放置过的窗口可能只显示变化的部分（悬停的行、滚动条），其余为空白。WSLPilot 现在整帧绘制，不再使用 MyGo 0.8
  的局部重绘（见 `upstream.md` 的 MyGo 一节）。
- 容器 › 清理…：删除已停止的容器、未使用的网络、悬空或全部未使用的镜像，并可按需删除将没有容器使用的 Volume
  （不包括 Compose 项目的 Volume），逐个先备份。
- MyGo v0.8.1。

## 0.1.3

2026-11-06 发布。在 Windows 11 ARM64 上基于 WSL 3.0.3.0、WSLc 3.0.3.0 与 MyGo v0.8.0 测试。

- 可以删除备份版本，也可以在版本上右键删除。增量仓库中的版本会合并到下一个版本：之后的版本也包含的数据会保留，只释放它独有的数据；
  删除最后一个版本时会删除整个仓库。
- 设置 › 常规：在“登录时打开 WSLPilot”下新增“启动到托盘”（默认开启；关闭后登录时会打开窗口）。
- 侧边栏可以收起为一列图标并再展开（应用名称旁的按钮），与 Kyokai 相同。
- 面板距窗口边缘 8 px（距侧边栏 4 px），在 Windows 上圆角为 4 px，与 Kyokai 相同，圆角不再比窗口的更圆。
- 新的应用图标：为 WSLPilot 绘制的简洁企鹅，取代原来的窗口加仿 Tux 企鹅。
- 修正：视图测试在共享的更新通道上存在数据竞争，且可能在后台保存完成前结束，导致 CI 的竞争检测失败。

## 0.1.2

2026-11-06 发布。在 Windows 11 ARM64 上基于 WSL 3.0.3.0、WSLc 3.0.3.0 与 MyGo v0.8.0 测试。

- Compose 项目备份成为一个备份项，包含项目文件、bind 目录与命名 Volume（布局版本 2，见 `backups.md`）；备份时停止项目以获得一致的副本，
  结束后再启动其服务。适用于目录、归档与增量备份。还原时可以还原整个项目或其中一个 Volume。0.1.0 与 0.1.1 的备份仍可还原。
- Compose 项目页显示每个服务的端口与挂载，以及“数据”卡片：以 Volume 页面相同的方式列出项目的 Volume 与目录；“备份项目…”会先说明备份包含的内容。
  Volume 页面会显示 Volume 所属的项目。
- 修正：“删除未使用的”不再删除已 down 的 Compose 项目的 Volume。
- 用词更清楚：“移除容器…”（compose down）、“从 WSLPilot 中移除…”、验证结果，以及备份计划编辑器（时间表与类型用文字显示，时间从列表中选择，
  说明每条保留规则保留什么）；计划卡片改为单列的“标签 — 值”。
- “设置 › 常规”新增“语言”（跟随 Windows、English、简体中文）。
- MyGo v0.8.0。

## 0.1.1

2026-11-05 发布。重新设计的界面；数据层与格式不变。在 Windows 11 ARM64 上基于 WSL 3.0.3.0、WSLc 3.0.3.0 与 MyGo v0.7.4
测试。

- 新窗口：Mica 背景、带图标的侧边栏、浮起的页面面板（其页眉即标题栏），以及 WSLPilot 自绘、支持贴靠布局的窗口按钮
  （`gui.md`）。
- 依照设计稿重做全部页面：概览中的统计卡与磁盘占用条，带状态圆点与胶囊的表格，含内嵌压缩面板的发行版卡片，独立的发行版设置页面，
  以控制台显示的容器日志，以还原为先的备份页面，内嵌 TAR 导入的 Volume 页面，任务页面。
- 设置改为可搜索、分组的设置面板（常规、备份与代理、WSL 容器、关于与更新）。
- 在应用内安装更新：每天检查、每个版本只提醒一次、带进度的“安装并重启”，以及可选的空闲时或指定时刻自动安装；不再使用 MyGo 的更新窗口。
  托盘新增“检查更新”。
- 关闭窗口可以选择直接退出而不是保留在托盘；第一次关闭时会说明窗口去了哪里。
- 修复：由概览先加载的列表不再一开始就选中某一行（Compose 曾直接打开第一个项目）；数量显示为“1 image”而非“1 images”。

## 0.1.0

2026-11-05 发布，首个版本。在 Windows 11 ARM64 上基于 WSL 3.0.3.0、WSLc 3.0.3.0 与 MyGo v0.7.4 测试；CI 构建并测试
x64 与 ARM64。

- WSL 发行版：安装、导入、导出、启停、设为默认、WSL 1/2 转换、迁移、调整大小、稀疏磁盘、磁盘压缩（`wsl --manage --compact`，
  旧版 WSL 则在提权窗口中运行 diskpart）、默认用户、软件包更新、终端。
- 设置以表单呈现，直接编辑原文件归入“高级”：`.wslconfig`、`wsl.conf`、WSLc `settings.yaml`；只重写修改的行，保存前备份。
- WSL 容器：容器、镜像、网络、日志、Shell、运行、编辑配置（先做安全导出）、重启策略、把容器数据迁移到其它目录。
- Compose：内置 Backend，校验时报告所有不支持的键；每个 Volume 可选原生 Volume 或 Windows 目录；登录时自启。
- Volume：经辅助容器以 TAR 导入导出（保留属主、权限与链接）；辅助镜像可配置。
- 备份：目录、归档与增量仓库（可选加密），以恢复为中心、可打开任意来源备份的目录，带保留策略与重试的计划，后台 agent。
- 托盘、登录时启动、通知、浅色与深色主题、英文与简体中文、来自 GitHub Releases 的签名自动更新。
